# eduardomachacon.com (versión 1)

Primera versión de mi sitio web personal, desplegada en Hostinger. Sitio en PHP con plantillas reutilizables (`includes/header.php` y `includes/footer.php`), formulario de contacto y configuración de rutas según el entorno (local o producción).

Integra dos proyectos propios:
- **Ahorcado** (`proyectos/ahorcado`): juego en PHP con autoload de Composer.
- **Finanzas App** (`proyectos/finanzas-app`): versión inicial de [finance-app](https://github.com/Ed4ard6/finance-app).

> Este sitio fue reemplazado por **[my-portfolio](https://github.com/Ed4ard6/my-portfolio)**, que incluye panel administrativo, base de datos y despliegue automatizado.

**Stack:** PHP, HTML, CSS y JavaScript.
